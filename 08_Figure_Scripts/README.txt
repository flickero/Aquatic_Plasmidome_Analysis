# Workflow 08 - Figure Scripts

## Overview

This workflow generates the publication-quality figures presented in Chapter 4 of the thesis from processed analysis outputs produced in previous workflows. The scripts create reproducible visualizations for plasmid characteristics and functional annotation, ensuring that all figures can be regenerated directly from the analysis pipeline.

---

## Workflow Summary

This workflow consists of three independent R scripts:

1. **generate_plasmid_figures.R**
   - Generates Figures 4.1-4.4.
   - Produces summary statistics accompanying each figure.

2. **Figure_45_generator.R**
   - Generates Figure 4.5.
   - Global functional composition of the plasmidome based on eggNOG COG annotations.

3. **Stacked_Two_Panels.R**
   - Generates Figure 4.6.
   - Sample-level functional composition integrating eggNOG annotations, plasmid occurrence, and sample metadata.

---

## Inputs

Depending on the script, inputs include:

- ORF prediction summary tables
- eggNOG annotation files
- Plasmid coverage matrix
- Alexander River metadata
- Bogotá River metadata

These files are generated by previous repository workflows.

---

## Outputs

### Figures 4.1-4.4

Generated by:

```
generate_plasmid_figures.R
```

Outputs include:

- Plasmid length distribution
- ORF count distribution
- ORF length distribution
- ORF-to-plasmid length ratio
- Summary statistics (CSV)

---

### Figure 4.5

Generated by:

```
Figure_45_generator.R
```

Outputs include:

- Global COG functional composition
- Panel A (including Function Unknown)
- Panel B (excluding Function Unknown)

---

### Figure 4.6

Generated by:

```
Stacked_Two_Panels.R
```

Outputs include:

- Sample-level COG functional composition
- Alexander River samples
- Bogotá River samples
- Publication-ready PNG and PDF figures
